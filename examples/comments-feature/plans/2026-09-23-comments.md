# 实现计划：comments

> **来源需求**：../requirements/2026-09-23-comments.md
> **生成时间**：2026-09-23T10:00:00+08:00

## Goal

在 Docmost 中实现文档评论功能，支持添加、查看、删除评论，遵循 NestJS 架构和 TDD 流程。

## Architecture

新增 `comments` 核心模块，包含 entity、service、controller 三层。前端使用 Mantine UI 组件构建评论输入框和列表。权限复用现有的 CASL ability 系统。

## Tech Stack

- 后端：NestJS + TypeORM + PostgreSQL
- 前端：React + Mantine + TipTap
- 测试：Jest (后端) + Vitest (前端)
- 权限：@casl/ability
