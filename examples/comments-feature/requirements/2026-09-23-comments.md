# 需求：文档评论功能

> **创建日期**：2026-09-23
> **负责人**：wuxiufeng
> **目标分支**：feature-wxf

---

## 背景与目标

Docmost 作为协作式 wiki，需要让团队成员对文档进行讨论和反馈。评论功能允许用户在文档下方留下评论，是协作的基础能力。

## 功能点

### F1: 添加评论
- 在文档下方显示评论输入框
- 用户输入评论后点击提交
- 评论实时显示在文档下方
- 空评论提交被拒绝并提示

### F2: 查看评论列表
- 文档下方按时间倒序列出所有评论
- 每条评论显示作者头像、用户名、时间、内容

### F3: 删除评论
- 评论作者或空间管理员可以删除评论
- 删除后立即从列表中移除

### F4: 编辑评论（v2）
- 评论作者可以编辑自己评论
- 编辑后显示"已编辑"标记

## 非功能需求

- **性能**：评论列表加载 < 200ms（100 条评论内）
- **安全**：只有有文档阅读权限的用户才能查看评论
- **兼容性**：支持现代浏览器（Chrome/Firefox/Safari/Edge 最近 2 版）

## 验收标准

- [ ] 有阅读权限的用户能在文档下方看到评论输入框
- [ ] 提交评论后评论立即显示在列表中
- [ ] 空评论提交被拒绝并显示错误提示
- [ ] 评论列表按时间倒序排列
- [ ] 评论作者能删除自己的评论
- [ ] 空间管理员能删除任何评论
- [ ] 无权限用户看不到评论输入框

## 不考虑的范围

- 不支持评论回复（一层结构，不做嵌套）
- 不支持 @mention
- 不支持富文本（纯文本评论）
- 不支持评论通知（WebSocket 推送 v2 再加）
