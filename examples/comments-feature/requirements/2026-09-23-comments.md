# 需求：文档评论功能

> **状态**：DRAFT
> **创建日期**：2026-09-23

---

## Problem

Docmost 作为协作式 wiki，需要让团队成员对文档进行讨论和反馈。当前缺少评论功能，协作者只能依赖外部沟通工具，导致上下文碎片化。

## Behaviors

- 有阅读权限的用户可在文档下方输入评论并提交
- 评论实时显示在文档下方，按时间倒序排列
- 每条评论显示作者信息（头像、用户名、时间）和内容
- 评论作者或空间管理员可删除评论
- 空评论提交被拒绝并提示

## Acceptance Criteria

- [ ] 有阅读权限的用户能看到评论输入框 → verifiable by 前端测试
- [ ] 提交评论后立即显示在列表中 → verifiable by E2E 测试
- [ ] 空评论提交被拒绝并显示错误提示 → verifiable by 单元测试
- [ ] 评论列表按时间倒序排列 → verifiable by 单元测试
- [ ] 评论作者能删除自己的评论 → verifiable by 权限测试
- [ ] 空间管理员能删除任何评论 → verifiable by 权限测试
- [ ] 无权限用户看不到评论输入框 → verifiable by 前端测试

## Context

- **Tech stack**: NestJS + TypeORM + PostgreSQL (后端), React + Mantine (前端)
- **Related features**: 文档权限系统 (CASL)、用户认证
- **Constraints**: 评论列表加载 < 200ms（100 条评论内）
- **Non-goals**: 不支持嵌套回复、@mention、富文本、WebSocket 推送（均为 v2 范围）
